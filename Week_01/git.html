Git and GitHub

1. Understanding Git and GitHub

Git is the tool that tracks and saves changes in the code on your computer.

GitHub is a website where you can put that project online so you can share it or work on it with other people.

So Git does the tracking and GitHub does the sharing.

2. VS Code Source Control Process

I open my project in VS Code and click the Source Control icon on the left. It shows all the files I changed.

I click the + to stage the files I want to save. Then I type or ask AI to write a short message in the box at the top.

After that, I hit the checkmark to commit. If I want it on GitHub, I press Sync at the bottom.
